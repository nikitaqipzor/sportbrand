# Athletica AI

Мультиспортивное фитнес-приложение для Android: зал, плавание, велосипед и баскетбол в одном адаптивном плане.

> **Статус: прототип, а не приложение.** В репозитории есть проработанный дизайн на 26 экранов, продуктовые аудиты и каркас мобильной монорепо. Работающего приложения, которое можно поставить на телефон, пока нет. Путь от текущего состояния до беты описан в [docs/ROADMAP.md](docs/ROADMAP.md).

## Важно про аудиты

`product-materials/ai-fitness-os-full-audit-4c.md` и `ai-fitness-os-qa-audit.md` оценивают **другую кодовую базу** — Go-бэкенд с 18 парами миграций и React Native приложение на 28 экранов с Health Connect и CameraX. Этого кода в репозитории нет.

Если он существует отдельно — его нужно найти и добавить: тогда аудиты становятся списком задач по закрытию блокеров, а не описанием утраченной работы. Если он утрачен — аудиты остаются ценной спецификацией того, что нужно построить. Это первое решение из [плана](docs/ROADMAP.md#два-решения-которые-нужно-принять-до-фазы-1).

## Быстрый старт

Веб-прототип:

```bash
cd source/web-prototype
npm ci
npm run dev
```

Мобильная монорепо и API:

```bash
cd source/mobile-beta-foundation
pnpm install
pnpm typecheck && pnpm test

# бэкенд
docker compose -f infra/compose/docker-compose.yml up -d
cd services/api && go test ./...
```

Подробности — в README внутри каждой папки.

## Целевая петля беты

```
Сегодня → активная силовая тренировка → лог подхода → офлайн-очередь → синхронизация → итоги → прогресс
```

Пока эта петля не проходит целиком на реальном устройстве, продукт находится в Фазе 1.

## Принципы работы

- Вертикальный срез вместо горизонтальных слоёв.
- `openapi.yaml` — источник истины на границе клиента и сервера, меняется раньше кода.
- Каждый инвариант (идемпотентность записи, изоляция пользователей, очистка при выходе) закреплён тестом.
- Готово = проверено на устройстве, а не «код написан».
