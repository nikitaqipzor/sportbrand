# Athletica AI — полный пакет проекта

Дата сборки: 4 сентября 2026.

Это единый архив всех доступных в рабочем пространстве материалов Athletica AI. Он создан, чтобы не смешивать уже работающий веб-прототип с отдельной, пока стартовой мобильной веткой.

## Состав

| Папка | Что внутри | Статус |
| --- | --- | --- |
| `source/web-prototype` | Полные исходники опубликованного интерактивного веб-прототипа: экраны, навигация, тесты, стили, изображения, конфигурация и lock-файл. | Работает как демонстрационный веб-прототип. |
| `source/mobile-beta-foundation` | Начальная Android-first монорепо-основа: Expo-маршруты, доменные типы тренировок, конфигурация API, offline-outbox, OpenAPI-контракт, Docker Compose для PostgreSQL и архитектурные решения. | Каркас Sprint 1, не готовое мобильное приложение. |
| `product-materials` | Дизайн-бриф, QA- и полный аудит, веб-превью, энциклопедия упражнений, шаблон карточки упражнения и визуальные материалы. | Исходные продуктовые материалы. |

## Что реально готово

- Веб-прототип Athletica AI опубликован и содержит 26 ключевых экранов, рабочую навигацию, онбординг и интерактивные сценарии тренировок.
- В `source/web-prototype` есть полный исходный код именно этого прототипа, а не пустая заготовка.
- Мобильная ветка честно отделена: в ней уже зафиксированы архитектура и контракты, но нет реализованного Go API, базы с миграциями, реальной авторизации, синхронизации, Android-сборки или CI.

## Почему прошлый архив был маленьким

Предыдущий файл содержал только новую ветку `mobile-beta-foundation`, созданную как первый пункт плана. Он не включал исходники уже опубликованного сайта и продуктовые материалы — это была ошибка комплектации, а не отсутствие ранее выполненной дизайн-работы.

## Запуск веб-прототипа локально

```bash
cd source/web-prototype
npm ci
npm run dev
```

Для проверок:

```bash
npm test
npm run lint
npm run build
```

## Ограничение пакета

В архив не включены `node_modules`, кеши сборки, секреты и переменные окружения. Зависимости восстанавливаются через lock-файл. Полноценного исходного репозитория прежней мобильной реализации в рабочем пространстве не было: если он существует отдельно, его нужно добавить к этому пакету до продолжения серверной и Android-разработки.
